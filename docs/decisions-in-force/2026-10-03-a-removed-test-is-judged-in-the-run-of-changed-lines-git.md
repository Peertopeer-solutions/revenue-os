- 2026-10-03 · **A removed test is judged in the run of changed lines git shows it in, and only a whole test moves**: a test is moved only when its first line and each expect line after it land together, in that order and with no other test starting between them, in a file a test runner runs (bun's `*.test.*`, `*_test.*`, `*.spec.*`, `*_spec.*`; Playwright's `*.e2e.ts`), so a test moved into a helper or a note, or an expect moved on its own (into another test included), is removed; a test renamed where it stood is an edit only while none of its expect lines go, otherwise it is rewritten and named under its old name; an expect rewritten where it stood is an edit unless the new one checks a constant (`expect(true)`, `expect(1)`, `expect("x")`); an `expect` line after a removed test's start goes with that test; a `whole file` line counts only for a file the change deletes, which is named once when nothing moved out of it ([#135](https://github.com/devesh911/revenue-os/pull/135)).
