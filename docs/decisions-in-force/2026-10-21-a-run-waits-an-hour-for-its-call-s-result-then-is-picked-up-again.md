- 2026-10-21 · **A run waits an hour for its call's result, then the scheduler picks it up again and never places the call twice** ([#199](https://github.com/Peertopeer-solutions/revenue-os/pull/199)): a run parked on a call wakes an hour after the call was queued (CALL_RESULT_WAIT_MS in services/worker/src/call-stops.ts); while the call's job or its dead letter is still queued, retrying or running in pg-boss, it waits another hour; otherwise it goes on from what the job saved: a result the call's own events filed (the outcome they gave, else how the call ended, a voicemail routed as no answer and a cancelled call as failed) is folded and the sequence goes on; a call placed with no result, a call whose dialer's answer was never saved, and a call never placed each hand the lead to a person; a call the calling hours held back is tried again an hour later; a run parked before this change has no wake-up time, so it is not picked up
