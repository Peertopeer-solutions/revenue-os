- 2026-10-03 · **What `bun run guards` counts as a pattern naming a file**: a word in backticks that reads as a path (it ends in "/", ends in a file extension, or starts with one of the repository's top-level files or folders), a word with a "/" ending in a file extension, a link's target (read from the pattern file's own folder) and an excerpt's first line, each looked up in what `git ls-files` lists (committed, or new and not ignored), never on disk (a `:12` line number after it allowed); a package or import path (`hono/cors`), a branch (`origin/main`), a word pair such as and/or, a web address and anything inside an excerpt are not names; a checkout with no pattern files fails.
