- 2026-09-29 · **Behaviour is proved by behaviour tests**: a test shows what the code does (calls it, renders it, drives it). Reading source code as text is allowed only in a structure check (such as which part may import which, or a banned command) or a secret scan. This replaces the older rule that no test reads source code. Such a check lives in lint or `bun run guards` (like the public-address check), never in a test file, so the done gate keeps refusing test files that read source code.
