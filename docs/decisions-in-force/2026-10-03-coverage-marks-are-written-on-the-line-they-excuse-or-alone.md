- 2026-10-03 · **Coverage marks are written on the line they excuse, or alone on the line above it, and quoted in the PR body**: `// coverage gap: <why>` (the why holds a word) or, on console code only, `// coverage: browser-only (<an .e2e.ts file under apps/console/e2e that exists>)`; a mark excuses its own line, and a mark alone on its line excuses the line below it too, the form JSX needs because the formatter moves a trailing `{/* … */}` onto a line of its own; a mark that doesn't hold is a problem and its line still counts; each mark on an added line of a .ts or .tsx file under apps, services or packages is a done-rules note naming the line the PR body owes it, and the PR body carries `Coverage mark: <file> · <what the mark says>` once per mark, the file named exactly, which `bun run gate pr` checks with main's copy.
