- 2026-10-06 · **Sign-in is the default on every worker route**: one middleware on every path (`requireAuthUnlessPublic`, services/worker/src/app.ts) lets a request through only when every route it reaches is on `PUBLIC_ROUTES` in services/worker/src/auth.ts (GET /health, GET /ready, GET /release, POST /webhooks/vapi/:orgId), each with a check of its own, so a catch-all beside a public route can't skip sign-in; a path no route serves answers 401 without sign-in and 404 with it; a sign-in token must carry an expiry and a user. The routes live in app.ts, so a test can ask every mounted route.
