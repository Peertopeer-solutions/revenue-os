- 2026-10-03 · **Waiting is neither a failure nor a pass**: `bun run proof <slice>` exits 1 when a step failed (or the slice has no steps) and 0 when every step passed or the rest only wait on Devesh; only a run whose every step passed can set a slice to done, which proof.yml marks by running its step "Every step passed" only then, since the job ends green either way. A step waits only while its STATE.md → Waiting on Devesh item is unticked: ticked yet missing from the run, or naming no item, it fails.
