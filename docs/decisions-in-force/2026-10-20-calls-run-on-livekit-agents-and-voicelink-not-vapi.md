- 2026-10-20 · **Calls run on LiveKit Agents and VoiceLink, not Vapi** (Devesh): hosted Vapi cannot carry Indian calls, so Slice 4 is rebuilt on the "B+" setup that the LiveKit and VoiceLink spike of 16 to 18 October led to: LiveKit Cloud carries the India phone line and hosts the voice agent in its Mumbai region; speech-to-text, the language model and the voice are bought directly from services that process the call in India and are named in rows, not code; every recording, per-turn timing and log stays in our own Mumbai systems; VoiceLink is the first carrier and Plivo the standby. The voice agent runs in its own Node service, services/voice, because LiveKit's agent library needs Node; LiveKit Agents is used there for the live audio loop alone, and every decision on a call (what to say, which tool, the next step) comes from the brain's role rows, tools and guard() through packages/harness, never from a second brain written for calls. It replaces docs/tech-stack.md T10's Vapi and T26's "no streaming voice loop in our code", which the same PR updates.
