# State

What actually works today and what is waiting on Devesh. The "What works today" table is overwritten, never
appended to: every PR that changes reality updates it in the same PR. A Where / why cell holds at most 600 characters
(where it runs, why it has its status, and a pointer); a row's longer text lives in docs/done-gate.md (the checks) or
docs/what-works-today.md (the product), which the same PR updates, and `bun run cycle --check` and `rules-from-main`
refuse a longer cell. Waiting items are ticked when Devesh delivers them, and a later PR may drop a ticked one (git
keeps it). Decisions in force and rule changes are one file each, in docs/decisions-in-force/ and docs/rule-changes/,
so two pull requests never edit the same lines for them.
History lives in `git log`; the previous long version of this file is
`docs/archive/STATE-until-2026-09-25.md`.

The current slice is worked out from `ROADMAP.md` (`bun run cycle --banner`), never copied here.
